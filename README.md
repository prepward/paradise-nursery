# Paradise Nursery

## Paradise Nursery Houseplant Shopping Application

Paradise Nursery is a front-end houseplant shopping application built with React.

The application allows users to browse a variety of houseplants, add plants to a shopping cart, adjust quantities, remove items, and view the total cost of their selected plants.

### Features

- Paradise Nursery landing page
- Houseplant product listing
- Multiple plant categories
- Add to Cart functionality
- Dynamic shopping cart count
- Shopping cart quantity controls
- Remove items from cart
- Dynamic total cost calculation
- Continue Shopping functionality
- Checkout placeholder

### Technologies

- React
- React Router
- Redux Toolkit
- React Redux
- CSS
